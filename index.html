Machine Learning

สมุดบันทึกภาคสนามสไตล์พิมพ์เขียว รวบรวม 14 อัลกอริทึมหลักของ Machine Learning แบ่งตามประเภทการเรียนรู้ พร้อมแผนภาพ วิธีการทำงาน ข้อดีข้อจำกัด และตัวอย่างการใช้งานจริงของแต่ละหัวข้อ

Supervised Learning

เรียนรู้แบบมีผู้สอน — ใช้ข้อมูลที่มีคำตอบ (label) กำกับไว้

Linear Regression
เส้นถดถอยเชิงเส้น
Logistic Regression
ถดถอยโลจิสติก
k-Nearest Neighbors (kNN)
เพื่อนบ้านใกล้ที่สุด k ตัว
Decision Tree
ต้นไม้ตัดสินใจ
Random Forest
ป่าต้นไม้สุ่ม
Support Vector Machine (SVM)
ซัพพอร์ตเวกเตอร์แมชชีน
K-Means
การจัดกลุ่มแบบ K-Means
MLP (Neural Network)
โครงข่ายประสาทเทียมหลายชั้น

Unsupervised / Deep Learning

เรียนรู้จากข้อมูลดิบ หรือโครงสร้างเครือข่ายประสาทเชิงลึก

CNN (Convolutional Neural Network)
โครงข่ายประสาทแบบคอนโวลูชัน
LSTM (Long Short-Term Memory)
โครงข่ายความจำระยะสั้นแบบยาว
Transformer
โครงข่ายทรานส์ฟอร์เมอร์

Reinforcement Learning

เรียนรู้จากการลองผิดลองถูกและรางวัลตอบแทน

Reinforcement Learning
การเรียนรู้แบบเสริมกำลัง

ถ้ามีเวลา (Bonus)

หัวข้อเสริม สำหรับต่อยอดเมื่อมีเวลาเพียงพอ

XGBoost
Extreme Gradient Boosting
Stacking
การซ้อนโมเดล (Stacked Generalization)
