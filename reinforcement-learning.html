How it works

The agent learns a Q-value for each state-action pair. It receives rewards and gradually prefers actions that lead to higher long-term return.

Q(s,a) ← Q(s,a) + α[r + γ max Q(s',a') − Q(s,a)]

Parameter Tuning

Learning rate αHigher values learn faster but can be less stable.
Discount γHigher values emphasize future rewards.
