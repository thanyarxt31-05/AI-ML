# ML Algorithm Visualizer

Interactive one-page-per-algorithm Machine Learning visualization project.

## Included
- Supervised Learning: Linear Regression, Logistic Regression, kNN, Decision Tree, Random Forest, SVM, MLP, XGBoost, Stacking
- Unsupervised / Representation Learning: K-Means, CNN, LSTM, Transformer
- Reinforcement Learning: Q-Learning
- Parameter tuning sliders
- Interactive charts
- Synthetic data generation
- GitHub Pages compatible
- No backend required

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
1. Create a repository.
2. Upload the entire project.
3. Go to Settings → Pages.
4. Select the `main` branch and `/root`.
5. Save and open the generated Pages URL.

## Notes
CNN, LSTM, and Transformer pages are educational architecture visualizations. They do not train a full deep-learning model in the browser.
